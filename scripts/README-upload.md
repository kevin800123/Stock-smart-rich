# 每日選股 CSV 自動上傳（免手動）

目標：XQ全球贏家 排程自動選股並匯出 CSV → 本機資料夾 → 這支小工具偵測新檔自動送到雲端
`/api/csv/upload` → 雲端立即匯入，並在選股表自動算出蘭質/蘭值（沿用 XQ/蘭弦匯出值）與
木質/木率（見 `CLAUDE.md`「木質／木率」段）。

雲端這端**不需要任何改動**——`/api/csv/upload` 早就存在，收到檔就會做完整套匯入。缺的只是
「檔案怎麼從你的電腦送過去」這一段，這支腳本就是補這一段。

> **這是 Stage 1**：仍然依賴 XQ 每天在你電腦上把檔匯出到資料夾，只是免去你自己按上傳。
> 蘭質/蘭值是蘭弦的付費專有指標，無法由本站重算，因此這條路徑**保留了你每天要有 XQ
> 排程跑選股並匯出**這個前提；本站無法上網取得蘭弦資料，也不會嘗試代為登入或抓取 XQ。

## A. XQ 端：選股自動跑，匯出仍手動點一下

這是 XQ全球贏家（第三方桌面軟體）本身的設定，不在本站控制範圍內。查過官方文件與論壇後
確認的實況：**選股可以排程自動跑，但存成檔案這一步目前沒有找到能排程/免點擊的做法**——
所以以下流程把「手動」壓縮到每天一次點擊，而不是假裝能做到完全零手動。

1. **建策略**：在 XQ 選股中心把你目前在用的那份選股條件（含蘭質/蘭值等欄位的 XS 腳本）
   存成一個策略。
2. **啟動每日自動執行**：選中該策略 → 點上方「**每日自動執行**」鍵；或右鍵該策略 →
   「**啟動每日自動執行**」（[官方教學](https://www.xq.com.tw/learning/%E9%81%B8%E8%82%A1%E4%B8%AD%E5%BF%83%EF%BC%9A%E5%A6%82%E4%BD%95%E5%9F%B7%E8%A1%8C%E8%87%AA%E5%8B%95%E9%81%B8%E8%82%A1/)）。
   之後每天系統會自動重跑，結果自動同步到「報價組合 → 每日自動選股清單」，不必再手動按執行。
3. **每天匯出一次**：選股中心工具列的「匯出」按鈕 → 另存新檔 → 固定存到同一個資料夾。
   **建議資料夾（已幫你建好）**：
   ```
   C:\Users\kevin\XQExport
   ```
   第一次另存時手動選這個路徑，之後大多數存檔對話框會記住上次路徑，之後多半只要
   Ctrl+S／Enter 確認即可。**檔名不必每天不同**——上傳器只認「這個資料夾裡 mtime 最新
   的檔」，同檔名被覆寫、mtime 更新一樣抓得到。
   避免存到 `Documents`/`Desktop`（許多 Windows 安裝會把這兩個資料夾重新導向到 OneDrive
   同步，寫檔中途可能被鎖住或延遲同步）或本 repo 資料夾內（會被 git 注意到）。

**選配、想再省一步**：開機自動打開 XQ 有官方確認的做法——工作排程器建工作、觸發條件選
「在您登入後執行」、程式路徑指到 XQ 執行檔；或把 XQ 捷徑丟進啟動資料夾（`Win+R` 輸入
`shell:startup`）。但截至查到的資料，**自動登入**當時官方回覆仍「優化中」，不保證你這版
能免密碼登入——這步能省多少要看你目前的 XQ 版本，值得你自己實測一次。

## B. 排程執行上傳器

上傳器：[`upload_xq.ps1`](upload_xq.ps1)。相容 Windows PowerShell 5.1（用 .NET
`HttpClient` 手動組 multipart，不依賴 PS7 才有的 `Invoke-RestMethod -Form`）。

### 1. 準備參數

複製一份範例並填好參數（**不要把真實密碼提交進 git**——`.gitignore` 已排除
`scripts/run_upload.ps1`，只要複本用這個檔名就不會被追蹤）：

```powershell
Copy-Item scripts\upload_xq.example.ps1 scripts\run_upload.ps1
notepad scripts\run_upload.ps1
```

編輯 `run_upload.ps1` 內的：
- `$BaseUrl` — 你的 Zeabur 網域，例如 `https://your-app.zeabur.app`
- `$User` — 雲端 `SPR_BASIC_USER`（沒設 Basic Auth 就留空字串 `''`）
- `$Folder` — 步驟 A 的匯出資料夾

密碼**不要**寫進這個檔，改用環境變數（見下）。

### 2. 建立 Windows 工作排程器任務

開始 → 工作排程器 → 建立基本工作：

- **觸發**：每天，時間設在 XQ 匯出完成之後（抓 5–10 分鐘緩衝，例如 XQ 排程 08:30 匯出，
  這裡設 08:40）。
- **動作**：啟動程式
  - 程式/指令碼：`powershell.exe`
  - 引數：
    ```
    -NoProfile -ExecutionPolicy Bypass -Command "$env:SPR_BASIC_PASS='你的密碼'; & 'C:\完整路徑\scripts\run_upload.ps1'"
    ```
    （把密碼放在觸發指令而非檔案裡，是為了不讓密碼留在明文檔案中；也可以改用工作排程器
    的「以另一個帳戶執行」搭配憑證管理員，或改讀一個你自行用 ACL 保護的密碼檔——依你對
    這台機器的信任程度取捨即可，這裡給的是最簡單能動的版本。）
  - 開始位置：`C:\完整路徑\scripts`
- 「不管使用者是否登入均執行」＋「以最高權限執行」，確保排程器背景也能跑。

### 3. 手動先跑一次驗證

```powershell
$env:SPR_BASIC_PASS = '你的密碼'
.\scripts\run_upload.ps1
```

預期輸出 `上傳成功：<檔名> → snap_date=2026-xx-xx count=<列數>`。若印出「已上傳過同一檔，
略過」代表資料夾裡還是舊檔（XQ 還沒匯出新的），這是正常的冪等行為，不是錯誤。

## C. 怎麼確認自動化真的在跑

不需要另外查 log——打開雲端頁面，看**頂欄的資料新鮮度徽章**：交易日白天顯示今天日期
（非琥珀色）就代表今早的上傳成功了。也可以看選股表（總覽/選股頁）的**木率/木質欄**是否
與蘭值/蘭質一起隨每日新資料更新。

## 疑難排解

| 症狀 | 可能原因 |
|---|---|
| `找不到檔` / exit 2 | `$Folder` 路徑錯，或 XQ 排程沒有真的匯出新檔 |
| `上傳失敗 HTTP 401` | Basic Auth 帳密錯，或雲端有設但這裡沒帶 |
| `僅接受 .csv/.xlsx/.xlsm 檔案` | XQ 匯出格式不是這三種之一 |
| `檔案過大（上限 10MB）` | 匯出欄位/列數異常暴增，先檢查 XQ 那邊的選股條件 |
| 一直印「已上傳過同一檔，略過」 | XQ 排程沒有真的產生新檔——回頭檢查步驟 A |
