# 族群輪動頁重新設計（ui72）

## 目標與範圍

讓使用者打開「族群輪動」後 5 秒內回答三個問題：

1. 目前最強共振是哪個類股？
2. 哪個類股正在加速轉強？
3. 哪個類股正在快速外流？

**只改前端的資訊架構與視覺呈現。** `/api/sectors/flow` 與 `/api/sectors/picks` 的回應形狀、X／Y 的定義
（法人近 N 日淨買賣 ÷ 類股市值、大戶 400張↑ 週增 ÷ 類股市值）一律不動。點泡泡或排行篩選下方交叉選股的功能保留，
並擴充到摘要卡與放大鏡。

不改成純排序長條圖：法人／大戶雙軸與上期→本期的輪動方向都要留著。

## 已定案的決定（2026-09-23 使用者選擇）

| 項目 | 決定 |
|---|---|
| 放大鏡位置 | 並排：主圖（全範圍）在左；右欄上半是核心放大鏡，下半是象限領先者 |
| 加速轉強／風險外流 | 加一道條件：加速轉強只從「本期綜合值 > 0」挑，風險外流只從「< 0」挑 |
| 放大鏡範圍 | 自適應，框住至少 80% 類股的最小範圍（見 §1.2） |
| 正規化刻度 | 用放大鏡的 X 寬、Y 寬，不用主圖全範圍（見 §1.3） |

## 1. 資料模型：`flowModel(d)`

新增一個**純函式**（`web/app.js`，不碰 DOM），輸入 `/api/sectors/flow` 的回應，輸出畫面需要的全部判定。
主圖、放大鏡、摘要卡、象限領先者、標籤、細節列、頁首判讀**都只讀這一份結果**，同一個類股在不同區塊不會有不同的判定。

### 1.1 輸入與樣本

- `secs`＝`d.sectors` 中 `x` 與 `y` 都不是 null 的類股。
- `hasPrev(s)`＝`d.has_tail && s.x_prev != null && s.y_prev != null`。
- 象限沿用既有 `flowQuadrant`：`x>0 && y>0`＝雙流入（in）、`x<=0 && y>0`＝大戶增・法人賣（big）、
  `x>0 && y<=0`＝法人買・大戶減（inst）、其餘＝雙流出（out）。

### 1.2 核心放大鏡的範圍（「中央約 80%」）

- 百分位 `q(values, p)`：排序後線性內插（同 numpy 預設）。
- `window(t)`：X 軸取 `[min(q(xs,t),0), max(q(xs,1−t),0)]`，Y 軸同理（**一定含原點**，象限線才看得到），
  再往兩側各加寬度的 12% 當邊界。
- 從 `t = 0.10` 開始；框內類股數少於 `ceil(0.8 × n)` 就把 `t` 減 0.01 再算，直到框住至少 80% 或 `t = 0`。
- 兩軸同比例修剪、座標線性，沒有任何非線性轉換。框外的類股只在主圖出現。
- 規則與當下的修剪比例、框住幾類，都寫進「指標說明」。

2026-09-23 真實資料：`t = 0.08`，X `[−0.227, 0.382]`、Y `[−0.270, 0.168]`，**框住 28/34（82%）**。
框外 6 類：光電、航運、水泥、文化創意、通信網路、其他。

對照：固定修 10% 只框住 25/34（74%），固定修 5% 框住 31/34（91%）。

### 1.3 正規化刻度

- `wx`、`wy`＝放大鏡（含邊界）的 X 寬、Y 寬。今天 `wx = 0.610`、`wy = 0.438`。
- `nx = x/wx`、`ny = y/wy`，**綜合值** `comp = nx + ny`。
- 有上期的類股：`dnx = (x − x_prev)/wx`、`dny = (y − y_prev)/wy`，**右上位移** `move = dnx + dny`，
  **位移量** `mag = hypot(dnx, dny)`。

不用主圖全範圍當刻度的原因：主圖 Y 軸被汽車上期的 −1.267 撐開，用它正規化，Y 的變化會被壓到約三分之一，
結果變成 X 主導（今天「加速轉強」會變成文化創意），違反「避免單一軸主導」。放大鏡寬度由中央 80% 決定，
不受單一離群值影響。

### 1.4 三張摘要卡的規則

| 卡片 | 規則 | 今天 |
|---|---|---|
| 最強共振 | 雙流入象限中 `comp` 最大 | 航運（1.27） |
| 加速轉強 | `hasPrev` 且 `comp > 0` 且 `move > 0` 中 `move` 最大 | 汽車（3.05） |
| 風險外流 | `hasPrev` 且 `comp < 0` 且 `move < 0` 中 `move` 最小 | 光電（−2.51） |

- `move > 0`／`< 0` 的要求：全部類股都惡化的日子，不能把「惡化最少的」叫做加速轉強。
- 同一類股可以同時出現在兩張卡（各自回答不同的問題，照實呈現）。
- 找不到符合的類股時，卡片顯示原因、不可點（見 §4）。

### 1.5 其他輸出

- **常駐標籤**（§7）：三張卡的類股 → 依 `mag` 由大到小補到 7 個 → 加上目前選取的類股（最多 8 個）。
  今天：航運、汽車、光電、資訊服務、文化創意、水泥、化學。
- **象限領先者**（§9）：每個象限依 `hypot(nx, ny)` 由大到小取前 3，另給該象限類股數。
  今天：雙流入 8 類（航運、電機機械、化學）；大戶增・法人賣 5 類（其他、電腦及週邊設備、玻璃陶瓷）；
  法人買・大戶減 15 類（光電、水泥、文化創意）；雙流出 6 類（通信網路、塑膠、綠能環保）。
- **主圖範圍**：X、Y 各取「本期＋上期＋原點」的最小到最大，兩側各加 6%，線性、不對稱。
  今天 X `[−0.429, 0.619]`、Y `[−1.383, 0.787]`；舊版對稱 ±0.62、±1.39，Y 軸省下約 22% 的空白、X 軸約 15%。

## 3. 頁首

- 標題「族群輪動」下只留**一句白話判讀**，由三張卡組成，例如：
  「航運雙流入最強、汽車轉強最快、光電外流最急。」缺哪張卡就少那一句；三張都沒有時寫
  「今天沒有明顯的雙流入或輪動訊號。」
- 一排 compact chips（取代現在那段長括號說明）：
  - 「法人 09-17～09-23・5 日」、「上期 09-10～09-16」（上期跨距過長時加「不連續」，沿用既有判斷）
  - 「集保 09-11→09-18」、「上期集保 09-04→09-11」（不相鄰時改成「上期集保跨 N 週・無向量」，沿用既有措辭邏輯）
  - 「34 類股」；「36 檔缺收盤」「N 類算不出市值」只在大於 0 時出現
  - 「ⓘ 指標說明」按鈕：原生 `popover`，內容是 X／Y 公式、上期定義、放大鏡規則（含當天修剪比例與框住幾類）、
    正規化刻度（當天 `wx`／`wy`）、三張卡規則、「規則式摘要，非投資建議」。開啟時依按鈕位置定位；
    ESC 與點外面關閉由瀏覽器處理。
- chips 列保留 `role="status" aria-live="polite"`（取代現在的 `#rotation-note`）。

## 4. 今日輪動摘要卡

- 列標題：「今日輪動摘要」＋小字「規則式・非投資建議」。
- 每張卡是一個 `<button type="button" aria-pressed>`，四行：
  1. 卡名（最強共振／加速轉強／風險外流）＋右側象限小標（用該象限顏色的細框，不填色）
  2. 類股名（粗體；過長時省略號＋`title` 全名）＋方向箭頭
  3. 「法人 +0.30%　大戶 +0.34%　雙流出 → 雙流入」（上期象限 → 本期象限；窄寬時換行）
  4. 一句判讀（小字）
- 方向箭頭：由 `(dnx, dny)` 的角度取八方位（→ ↗ ↑ ↖ ← ↙ ↓ ↘）；沒有上期時不顯示。
- 一句判讀的規則：
  - 最強共振：上期也在雙流入 →「連續兩期雙流入，兩軸合計最強」；否則「由〈上期象限〉轉為雙流入，兩軸合計最強」；
    沒有上期 →「法人與大戶同步流入，兩軸合計最強」。
  - 加速轉強：取 `dnx`、`dny` 較大的那一軸為主因 →「〈大戶｜法人〉改善最多：−1.27% → +0.00%」。
  - 風險外流：取較小（更負）的那一軸 →「〈大戶｜法人〉惡化最多：+0.67% → −0.67%」。
- 找不到符合的類股：最強共振「今天沒有雙流入的類股」；加速轉強「沒有類股本期轉正」；風險外流「沒有類股本期轉負」；
  沒有上期資料時兩張卡都寫原因（「法人資料不足 10 日，尚無上一期」或「上期集保不相鄰」）。此時按鈕 `disabled`。
- 點卡＝切換該類股的選取（與點泡泡、點排行同一個 `toggleRotationFilter`）。

## 5. 主圖與核心放大鏡

- 兩張 ECharts 散點圖共用同一套畫法（同一個 option 產生器，只差座標範圍與高度）。
- **主圖**：完整範圍（§1.5），並用虛線矩形（`markArea`，透明填色）標出放大鏡範圍，矩形角落標「放大鏡」。
- **放大鏡**：座標＝§1.2 的範圍；框外的泡泡與向量由 ECharts 裁切在繪圖區內（向量從邊界進來，方向仍看得到）。
  標題列寫「核心放大鏡・框住 28/34 類」。
- 兩張圖都畫 X=0、Y=0 象限線，四個象限各有極淡的同色底（flat tint，不用漸層），象限名稱寫在角落。
- 泡泡：大小沿用 `√市值`；填色＝所在象限的顏色（§11）、透明度 0.6，外框同色。
- tooltip 沿用站內 `financeTooltip`（`confine: true`，不會被裁切），內容：類股、當日漲跌（紅漲綠跌，唯一用紅綠的地方）、
  法人本期／上期／Δ、大戶本期／上期／Δ、樣本檔數、市值、法人買最多三檔。
- 視窗縮放：兩張圖都加進既有的 `window` resize 清單；載入時「先寫容器高度 → `setOption` → `resize()`」。

## 6. 方向向量

- 上期＝**空心圓**（固定 7px，外框用該類股**本期**的象限色，與本期泡泡同色，一眼看出是同一條向量）；本期＝**實心圓**（泡泡本身）。
- 連線用 ECharts `lines` 系列（`coordinateSystem: 'cartesian2d'`），拆成「上期→中點（終點畫箭頭）」與「中點→本期」兩段，
  箭頭落在中點，不會被本期的泡泡蓋住。
- 圖例：圖表右上角一行「○ 上期 → ● 本期」。
- 一般狀態：所有向量細線（1px）、低透明度；選取時該類股向量 2.5px、其他泡泡與向量降到 25% 透明度。
- 沒有上期的類股不畫向量。

## 7. 標籤

- 主圖與放大鏡平時只顯示 §1.5 的常駐標籤（最多 8 個），其他類股名只在 hover、鍵盤 focus（對應的卡或排行列）、
  或被選取時出現（ECharts `emphasis.label`）。
- 標籤放在泡泡右上方，深色小底框（`backgroundColor` 半透明深色、圓角），壓在線或其他泡泡上也讀得到。
- 放大鏡只標在框內的常駐類股；框外的在主圖標。

## 8. 選取與互動

- 選取狀態仍是單一的 `rotationSectorFilter`；以下四種操作都呼叫 `toggleRotationFilter(sector)`：
  點摘要卡、點主圖泡泡、點放大鏡泡泡、點象限領先者列。再點同一個取消；細節列的「清除篩選」取消。
- 選取改變後：交叉選股照舊只切 `.hidden`（不重打 API）；兩張圖重畫選取樣式；卡、排行的 `aria-pressed` 更新；
  細節列更新；重繪後焦點回到原本那顆按鈕（沿用現有做法）。
- 鍵盤 focus 到某張卡或某一列時：兩張圖對該類股 `highlight`＋主圖 `showTip`；blur 時 `downplay`／`hideTip`。
  這是鍵盤使用者唯一能「指到」canvas 泡泡的方式。

## 9. 象限領先者

- 保留 2×2（雙流入、大戶增・法人賣、法人買・大戶減、雙流出），每格：象限名＋類股數＋Top 3。
- 每列是 `<button type="button" aria-pressed>`，兩行：類股名（過長省略號＋`title` 全名）／「法人 +0.30%　大戶 +0.34%」。
- 格子左側一條 3px 的象限色線；不加「其他」、不加展開、不加第二層。該象限沒有類股時寫「—」。

## 10. 選取細節列

- 位置：主圖與右欄下方，整列。
- 未選取：一行提示「點摘要卡、泡泡或右側排行，查看類股細節並篩選下方交叉選股」（佔位，版面不跳動）。
- 選取後一行（窄寬時換行）：類股｜象限（上期 → 本期）｜法人 +0.23%（Δ +0.36）｜大戶 −0.11%（Δ −0.27）｜
  法人買最多：2454 聯發科 507 億、2330 台積電 465 億、2303 聯電 224 億｜「清除篩選」按鈕。
- 主要貢獻個股就是 tooltip 已有的 `top3`（法人買最多），不新增 API。Δ 不著紅綠（資金流向不是漲跌）。

## 12. 無障礙與觸控

- 摘要卡、排行列、清除篩選、指標說明都是 `<button>`，可 Tab、Enter／Space 操作，沿用全站 `:focus-visible`。
- 選取狀態用 `aria-pressed`；不可用的卡用 `disabled`。
- 觸控目標至少 28px（排行列兩行約 40px）。
- 兩張圖保留 `role="img"` 與說明文字；放大鏡的 `aria-label` 寫出範圍與框住幾類。

## 13. 降級與錯誤

- **載入失敗**：沿用現有處理，並一併清空摘要卡、放大鏡、細節列、chips，不留上一次的內容。
